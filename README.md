# پلتفرم جامع رژیم و تغییر سبک زندگی ۹۰ روزه (Habit Stacking Platform)

این پروژه بر اساس نیازمندی‌های دقیق کارفرما برای ساخت یک سامانه اختصاصی سبک زندگی، رژیم درمانی تحت نظارت مستقیم پزشک («خانم دکتر»)، ردیابی عادات رفتاری (CBT) و سیستم فالوآپ پیوسته پیاده‌سازی شده است.

---

## 🌟 تمایزهای کلیدی سامانه
1. **پرسونال برندینگ اختصاصی پزشک**: رژیم‌ها رباتیک نیستند؛ مراجع حس می‌کند تحت نظارت مستقیم شخص خانم دکتر است.
2. **اتاق انتظار طلایی (۶ الی ۲۴ ساعت)**: پس از تکمیل پرونده و آپلود آزمایش خون و عکس‌های ۳۶۰ درجه، شمارش معکوس جهت تحلیل و تنظیم برنامه توسط پزشک آغاز می‌شود.
3. **تکنیک‌های انباشتی ۹۰ روزه (Habit Stacking)**:
   - روز ۱: ۲ لیوان آب قبل از وعده غذایی
   - روز ۲: ۲ لیوان آب + ۴ دور تنفس مربعی
   - روز ۳: آب + تنفس مربعی + قانون بشقاب نصف سبزیجات
   - روز ۴: غذا خوردن نشسته و بدون حواس‌پرتی
   - روز ۵: تکمیل جدول مزایای لاغری (تکنیک شناختی CBT)
   - و تا روز ۹۰، هر روز یک تکنیک جدید به همراه صوت و ویدیوی اختصاصی پزشک به برنامه افزوده می‌شود.
4. **سیستم فالوآپ و ریماندرهای هوشمند**: پیامک و نوتیفیکیشن‌های منظم برای آب، ورزش، تنفس و تکالیف روزانه.
5. **ارزیابی چندزاویه‌ای (عکس‌های ۳۶۰ درجه)**: ثبت تصاویر از ۴ زاویه (روبرو، پشت، نیم‌رخ چپ و راست).
6. **کارتابل اختصاصی خانم دکتر**: مشاهده آزمایش‌های خون، عکس‌ها، شاخص‌های هورمونی و صدور رژیم.

## 🚀 نحوه اجرا و دمو

برای اجرای وب‌سرور داخلی پروژه:
```bash

```

- **پنل پزشک (کارتابل خانم دکتر):** `http://localhost:8080/doctor.html`
