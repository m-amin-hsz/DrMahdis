# اپلیکیشن و پلتفرم اختصاصی SHOCK ⚡ (متد شوک دکتر مهدیس)

این پلتفرم اختصاصی برای **متد شوک لاغری، اصلاح سبک زندگی ۹۰ روزه (Habit Stacking) و رژیم‌درمانی بالینی تحت نظارت مستقیم دکتر مهدیس** (دامنه: `Drmadis.com`) طراحی و پیاده‌سازی شده است.

## 🌟 ویژگی‌های نسخه فعلی (Demo / MVP)
1. **صفحه ورودی متحرک (Splash Screen):** بارگذاری با تصویر اختصاصی `shock.jpg` و انیمیشن رعد و برق نئونی.
2. **آیکون اختصاصی Shock ⚡:** تنظیم در مانیفست PWA، مرورگرها و لانچر اندروید.
3. **متد ۹۰ روزه انباشتی (Cumulative Habit Stacking):** روز ۱ (آب)، روز ۲ (آب + تنفس مربعی)، روز ۳ (بشقاب سبزیجات)، روز ۴ (نشسته)، روز ۵ (کارت مزایای CBT) و ادامه تا روز ۹۰.
4. **پرونده بالینی مراجع:** ثبت قد، وزن، سن، وضعیت هورمونی و قاعدگی، آپلود برگه آزمایش خون و عکس‌های ۳۶۰ درجه (۴ زاویه).
5. **اتاق انتظار طلایی (۶ الی ۲۴ ساعت):** تایمر شمارش معکوس جهت ارزش‌گذاری روی تحلیل و تنظیم دستی پزشک.
6. **موتور فالوآپ هوشمند:** شبیه‌ساز نوتیفیکیشن‌ها و پیامک‌های یادآور آب، ورزش و تنفس روزانه.
7. **قابلیت ساخت خودکار فایل APK:** پشتیبانی کامل از GitHub Actions جهت بیلد خودکار `Shock.apk` در مسیر [`.github/workflows/build-apk.yml`](file:///home/amin/Projects/mahdis/.github/workflows/build-apk.yml).
